# AIPassport v0.1.0

Initial packaged release of the loopback OpenAI-compatible browser provider,
licensed under **AGPL-3.0-only**. The prebuilt executable targets **macOS arm64**
and requires a separately installed Google Chrome and an authenticated provider
profile. Repository visibility is unchanged; private releases require authorized
GitHub access.

## Included

- Chat Completions and Responses endpoints, streaming text, separately labeled
  reasoning, structured tool calls, and explicitly estimated usage.
- Request-authoritative instruction/conversation projection and bounded,
  process-memory, single-use Responses continuation history.
- Atomic checksum-verified installer and `version` / `--version` reporting.
- Project license, third-party notices, corresponding source archives,
  `SOURCE.md` rebuilding instructions, and SHA-256 checksums for release assets.

## Known limitations

This is not a claim that every live model passes strict workflow acceptance.
Release preparation recorded 230 passing local tests (225 repository tests and
five local native-observer diagnostics), but live acceptance remains
partially failed:

- Sonnet low and Terra low passed the observed five-request Chat tool workflow.
  Gemini Flash Lite grouped two tools in one request and failed that unchanged
  sequencing assertion.
- The actual Responses-client audit recorded 13 completed streaming responses
  and six expected error responses. Strict exact-output scenarios still failed
  on added spaces, punctuation/prose, or refusals. Later Gemini lifecycle cases
  were not reached after its initial refusal.
- A separate Terra source diagnostic matched the final spacing difference to
  the native reply. Full-run native attribution remains incomplete; it does not
  establish the origin of other models' failures.
- Large-context reliability, a native context limit, provider cache hits, hidden
  reasoning provenance, and billing-accurate usage are not established.
- Responses IDs are bounded, single-use, and process-local. Restarted, consumed,
  evicted, or oversized history cannot be continued; resend authoritative history
  as a new request. Stop a running provider before replacing its executable.

The existing failed reports and assertions have not been rewritten or relaxed,
and no unchanged live-model retries are part of this release preparation.
Raw local diagnostic files are not included in the source release.

## Installation and verification

Download the release assets using an authorized GitHub session. Verify
`checksums.txt`, retain the license/notices/source material, and run the executable's
`help` and `--version` commands before installation. `--version` must print
`0.1.0`. See the repository README for authenticated downloads and installation.
These binaries are ad-hoc signed, not Developer ID signed or notarized.
