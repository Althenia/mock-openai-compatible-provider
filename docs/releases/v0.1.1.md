# AIPassport v0.1.1

This release retains known timeout and live-model limitations. It is not a
verification that every model can complete a chat or execute client tools.
The prebuilt executable targets **macOS arm64**, requires separately installed
Google Chrome and an authenticated provider profile, and remains licensed under
**AGPL-3.0-only**.

## Changed

+ Attributed browser reasoning can stream before the final answer while remaining
  separate from answer text. Final answers and tool calls still pass turn-key and
  offered-action validation; a failure after reasoning progress terminates the
  stream rather than silently replaying the turn.
+ Structured replies identify actions for the external client dispatcher. The
  browser chat does not execute skills, file operations, shell commands, or MCP
  itself; only actions offered by the client can be requested.
+ Browser setup carries cancellation through model selection, temporary-chat
  setup, authentication, and submission. Unsettled setup and page cleanup block
  new turns until their owned resources are reclaimed.
+ Failure-stage diagnostics report bounded control/transport metadata. The new
  diagnostics exclude prompt text, attribute values, URLs, and error payloads.
+ The executable reports `0.1.1`. Release attachments remain the executable and
  one complete source archive containing application and bundled-component
  sources, licenses, notices, rebuilding instructions, installer, and checksums.

## Known limitations

+ The latest real YCoding acceptance run failed all five provider attempts with
  HTTP 502 because model confirmation exceeded its 20-second selection deadline.
  No prompt was submitted, no chat turn completed, and no tool call or usage was
  produced. The model-picker issue remains unresolved.
+ Protocol tests cover offered action names and schemas, including skills, file
  operations, and synthetic MCP actions. They do not prove live execution of
  those capabilities on this build. Earlier successful runs used different
  builds and must not be treated as current-build acceptance.
+ Local full-suite runs have intermittently timed out in browser fixtures,
  including DOM setup, priming, and late DOM evidence. Targeted passing checks
  do not erase these failures. Assertions and timeout gates are unchanged.
+ The earlier [live-model compatibility limitations](v0.1.0.md#known-limitations),
  including strict output formatting, refusals, and tool sequencing, have not
  been revalidated as resolved. Large-context reliability, native context limits,
  provider cache hits, hidden reasoning provenance, and billing-accurate usage
  remain unverified. Usage is explicitly estimated.
+ Responses continuation IDs remain bounded, single-use, and process-local.
  Restarted, consumed, evicted, or oversized history requires a new request with
  authoritative history. No stored-data migration is introduced by this release.

Raw local diagnostics and the local development backlog are not release assets.

## Installation and verification

Stop any running provider before replacing its executable, then install this
version using the maintained public installer:

```sh
curl -fsSL https://raw.githubusercontent.com/Althenia/mock-openai-compatible-provider/main/site/install.sh | sh -s -- --version 0.1.1
aipass-browser-provider --version
```

The version command must print `0.1.1`. The installer verifies GitHub's SHA-256
asset metadata before executing or replacing the binary. The executable is
ad-hoc signed, not Developer ID signed or notarized. Installation does not
restart a running provider.

For offline installation, place the executable beside the complete source
archive and extract it before checking and installing:

```sh
tar -xzf aipass-browser-provider-0.1.1-complete-source.tar.gz
shasum -a 256 -c checksums.txt
sh install.sh --version 0.1.1 --from-dir .
```

The existing `v0.1.0` release is not overwritten. To restore it, stop the provider
and select `--version 0.1.0` with the online installer or use that version's
verified offline directory. Preserve state/config directories; process-memory
Responses continuation IDs do not survive the restart.
